# Multi-Stack AI Code Review Framework

Comprehensive code review framework for AI-generated code across .NET APIs, React UIs, and Python E2E testing.

## 📚 Contents

This repository contains:

- **Review Guidelines** - Stack-specific review checklists and criteria
- **GitHub Actions Workflows** - Automated CI/CD validation
- **AI Prompts** - Claude/AI review agent templates
- **Pre-commit Hooks** - Local code quality checks
- **Documentation** - Best practices and patterns

## 🏗️ Stacks Covered

- **.NET API** - ASP.NET Core, EF Core, async patterns, security
- **React UI** - TypeScript, hooks, state management, accessibility
- **Python E2E** - pytest, API testing, UI automation, edge cases
