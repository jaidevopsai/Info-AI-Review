# Cross-Stack Review Prompt

Review the changed API, UI, and integration-test surfaces together. Compare OpenAPI or route definitions, generated or handwritten clients, DTO nullability, status codes, Problem Details fields, pagination, authentication, authorization, and E2E assertions.

Flag contract drift, inconsistent error handling, user or tenant isolation gaps, duplicated incompatible validation, missing integration coverage, payload or rendering regressions, and test assumptions that do not match production behavior.

Report findings with severity, exact file and line, impact, and fix. End with a concise contract summary and the highest-risk missing integration test.
